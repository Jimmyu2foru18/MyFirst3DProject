# MyFirst3DProject

## Overview
MyFirst3DProject is a 3D application developed in Unreal Engine. It serves as a structured foundation for exploring core engine mechanics, setting up player controllers, and building interactive level prototypes.

## What I Did
* Initialized the project structure, configuration files, and input mapping contexts within Unreal Engine.
* Integrated the standard mannequin assets with customized character blueprints, player controllers, and movement mechanics.
* Implemented core input actions for keyboard and mouse navigation.

## What I Am Doing
* Constructing modular prototyping environments using custom grid materials, physics-based jump pads, and interactive door blueprints.
* Refining actor communication and event handling within Unreal Engine workflows.

## What I Am Going to Use This For
* Serving as a foundational sandbox to test advanced 3D game mechanics, refine interactive environments, and deepen technical proficiency in Unreal Engine development.
